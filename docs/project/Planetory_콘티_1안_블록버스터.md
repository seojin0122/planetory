# Planetory 소개 영상 콘티 1안

## 블록버스터 예고편 — 《작은 신호, 새로운 세계》

- 상태: 공유·논의용 초안
- 목적: Planetory의 외계행성 후보 탐사 경험을 1분~1분 30초 영상으로 소개한다.
- 기준 길이: 75초
- 데이터 규모: 사용자 제공 수치인 **200억 개**를 반영한다. 집계 단위·대상 범위·기준일은 최종 제작 전 확인하며, 별이나 행성의 개수로 표현하지 않는다.
- 분위기: 고요한 우주 → 신호 포착 → 빠른 탐사 → 웅장한 초대
- 핵심 카피: **“다음 발견의 시작은, 당신의 클릭일지도.”**
- Jira: [S15P21C206-253 — 영상포트폴리오 시나리오](https://ssafy.atlassian.net/browse/S15P21C206-253)
- 내용 근거: [요구사항 명세서](../requirements/planetory-requirements-spec.md)의 핵심 가치와 탐사 흐름을 참고한다.
- 범위: 영상 기획만 다루며 코드·운영 설정·서비스 정본을 변경하지 않는다.

## 기획 의도

실제 별 관측 데이터에서 외계행성 후보의 신호를 직접 찾고, 다른 사람들과 분석을 나누는 경험을 소개한다. 관객을 우주 탐사에 참여하는 주인공으로 초대한다.

서비스 장면은 요구사항을 기준으로 구성한 연출안이다. 촬영 시 실제 시연 가능한 화면으로 맞춘다. 미확정 신호를 행성 발견 확정으로 표현하지 않는다.

## 타임라인

| 시간 | 화면·장면 | 내레이션·자막 | 음악·효과 |
|---|---|---|---|
| 0–7초 | 완전한 암전. 작은 별 하나가 나타난다. 별빛이 아주 미세하게 어두워진다. | **“별빛이 잠깐 어두워졌다.”** | 낮은 공간음. 짧은 신호음 한 번. |
| 7–15초 | 별 앞을 작은 행성이 지나가는 연출. 별의 밝기 변화가 선 그래프로 이어진다. | “그 작은 변화 속에… 새로운 세계의 단서가 있다.” | 저음이 서서히 커진다. |
| 15–23초 | 관측 데이터가 화면을 가득 채우다 암전한다. 거대한 숫자 **20,000,000,000**을 띄운 뒤 **200억 개의 데이터**로 전환해 3초간 고정한다. | 내레이션: **“200억 개의 데이터.”** → **“그 속에 숨은, 새로운 세계의 단서.”** | 숫자가 나타나는 순간 강한 저음 타격. 이후 일정한 박동이 시작된다. |
| 23–32초 | 노트북 앞의 평범한 사용자. 화면으로 카메라가 들어가며 Planetory 별지도로 전환한다. 별 하나를 선택한다. | “이제, 당신의 탐사가 시작된다.” | 음악이 잠깐 멎고 클릭 소리. 이후 비트 진입. |
| 32–46초 | 실제 서비스 시연. 밝기 변화 확인 → 반복 주기 선택 → 곡선 겹치기 → 어두워지는 구간 선택. 클릭과 화면 전환을 박자에 맞춘다. | **“살펴보고.”** / **“겹쳐보고.”** / **“숨은 신호를 찾다.”** 작은 설명: “TESS 실측 데이터로 외계행성 후보 탐사” | 타악기와 현악기가 빠르게 쌓인다. |
| 46–57초 | 사용자가 판단을 제출한다. 결과와 AI 점수를 살펴본 뒤, 분석을 공개하고 다른 참여자의 의견을 확인한다. | “나의 판단에, 다른 시선이 더해질 때.” | 음악이 한 단계 확장된다. |
| 57–66초 | 여러 사용자의 얼굴과 분석 화면을 빠르게 교차한다. 마지막에는 별지도가 넓게 펼쳐진다. | **“200억 개의 데이터에서”** → **“당신의 탐사가 시작된다.”** | 가장 웅장한 구간. 마지막에 강한 타격음. |
| 66–75초 | 암전 후 Planetory 로고. 배경에는 별빛과 아주 얇은 밝기 변화 곡선. 마지막 4초는 접속 주소·QR을 고정한다. | **“다음 발견의 시작은, 당신의 클릭일지도.”** / **“Planetory — 외계행성 후보 탐사에 참여하세요.”** | 긴 잔향과 짧은 신호음으로 마무리. |

## 연출 포인트

- 규모를 소개하는 핵심 장면은 15–23초로 둔다. 숫자와 내레이션을 동시에 제시하고, 57–66초에 다시 상기시켜 데이터 규모가 기억에 남도록 한다.
- 첫 장면의 **별빛 감소 → 그래프의 하락 → 사용자가 선택하는 구간**을 같은 모양으로 연결한다. 서비스가 무엇을 하는지 시각적으로 이해시키는 장치로 활용한다.
- 우주 영상 사이에 실제 서비스 화면을 충분히 보여준다. 특히 32–57초는 관객이 기능을 이해하는 구간으로 사용한다.
- 신호 탐색과 판단 과정을 클라이맥스로 삼는다.
- 실사 촬영은 사용자 한 명과 손·눈·모니터 클로즈업을 중심으로 구성한다. 여러 사용자 교차 장면은 팀원들의 짧은 추가 촬영으로 확보한다. 규모감은 우주 배경, 편집, 음향으로 만든다.

## 길이 조정

- **60초 버전:** 데이터 몽타주와 사용자 교차 장면을 줄이되, 200억 개 숫자 노출과 내레이션은 유지한다.
- **90초 버전:** 주기를 맞추자 흩어진 점들이 하나의 하락 패턴으로 모이는 장면을 더 길게 보여준다.

## 제작 전 확정 사항

- 실제 시연 가능한 서비스 화면과 촬영용 데이터
- Planetory 로고, 마지막 화면에 사용할 접속 주소·QR
- 출연자, 내레이션 담당자, 음악·우주 배경 소스
- 최종 영상 길이와 화면 비율
