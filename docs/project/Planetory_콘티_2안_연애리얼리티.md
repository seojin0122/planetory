# Planetory 소개 영상 콘티 2안

## 연애 리얼리티 티저 — 《그 신호를 다시 읽는 법》

- 상태: 공유·논의용 초안
- 목적: Planetory의 외계행성 후보 탐사 경험을 1분~1분 30초 영상으로 소개한다.
- 기준 길이: 75초
- 데이터 규모: 사용자 제공 수치인 **200억 개**를 반영한다. 집계 단위·대상 범위·기준일은 최종 제작 전 확인하며, 별이나 행성의 개수로 표현하지 않는다.
- 분위기: 담담한 인터뷰 → 의미심장한 신호 → 우주 탐사라는 반전 → 따뜻한 여운
- 핵심 카피: **“스쳐 지나간 빛에도, 다시 볼 이유가 있다.”**
- Jira: [S15P21C206-253 — 영상포트폴리오 시나리오](https://ssafy.atlassian.net/browse/S15P21C206-253)
- 내용 근거: [요구사항 명세서](../requirements/planetory-requirements-spec.md)의 핵심 가치와 탐사 흐름을 참고한다.
- 범위: 영상 기획만 다루며 코드·운영 설정·서비스 정본을 변경하지 않는다.

## 기획 의도

환승연애 같은 연애 리얼리티의 인터뷰, 침묵, 교차 편집 문법을 활용한다. 초반에는 사람 사이의 이야기처럼 보이고, 중반에 두 사람이 말하던 대상이 ‘별의 신호’였음이 드러난다. ‘신호를 해석한다’는 공통점으로 감정적 몰입을 서비스 경험에 연결한다.

서비스 장면은 요구사항을 기준으로 구성한 연출안이다. 촬영 시 실제 시연 가능한 화면으로 맞춘다. 미확정 신호를 행성 발견 확정으로 표현하지 않는다.

## 타임라인

| 시간 | 화면·장면 | 대사·자막 | 음악·효과 |
|---|---|---|---|
| 0–8초 | 따뜻한 조명의 인터뷰. 출연자 A가 시선을 내린 채 잠시 머뭇거린다. | 제작진: “처음엔 왜 그냥 지나쳤어요?” A: **“너무 작은 변화라서요.”** | 잔잔한 피아노. 대사 앞뒤로 짧은 침묵. |
| 8–17초 | 출연자 B의 인터뷰. 노트북을 바라보는 옆모습이 중간에 삽입된다. 화면 내용은 아직 감춘다. | B: **“근데… 자꾸 같은 순간에 달라지더라고요.”** | 피아노 위로 옅은 공간음. |
| 17–25초 | 서로 다른 자리에서 화면에 집중하는 A와 B. 마우스를 움직이는 손, 표정, 눈빛을 교차한다. | 중앙 자막: **“같은 신호를 보고도”** → **“우리는 다르게 생각했다.”** | 음악이 잦아든다. |
| 25–33초 | 제작진의 질문 뒤, A가 답한다. 처음으로 모니터 화면을 공개한다. 별빛의 밝기 변화 곡선이 보인다. | 제작진: “어떤 신호였는데요?” A: **“별빛이요. 주기적으로 어두워졌어요.”** | 한 박자 정적. 이후 맑은 신시사이저가 들어온다. |
| 33–47초 | 반전 직후 **200억 개의 데이터**를 화면 중앙에 3초간 제시한다. 숫자 뒤로 별지도가 펼쳐진다. 별 선택 → 반복 주기 조정 → 곡선을 겹쳐 하락 구간 확인으로 이어간다. | 내레이션: **“200억 개의 데이터 속에서, 그냥 지나칠 수 없는 신호를 만났다.”** 이어지는 자막: “실제 관측 데이터로 만나는 외계행성 후보 탐사.” | 피아노에 리듬이 더해진다. |
| 47–58초 | 분석 결과와 공유 화면. 같은 신호를 두고 서로의 분석을 확인한다. 마지막에는 함께 화면을 바라본다. | A: “저는 행성일 수도 있다고 봤어요.” B: **“저는 조금 더 확인해 보고 싶었어요.”** | 대사가 잘 들리도록 음악을 낮춘다. |
| 58–67초 | 초반 인터뷰 장면으로 돌아온다. A가 가볍게 웃는다. 별빛과 그래프가 천천히 겹쳐진다. | 제작진: “그래서, 다시 봤어요?” A: **“네. 이번엔 그냥 지나치고 싶지 않아서요.”** | 감정이 올라가되 과장하지 않는다. |
| 67–75초 | 밤하늘 위 Planetory 로고와 보조 문구 **“200억 개의 데이터, 당신이 읽어낼 다음 신호.”**를 표시한다. 마지막 4초는 접속 주소·QR을 고정한다. | **“스쳐 지나간 빛에도, 다시 볼 이유가 있다.”** / **“Planetory — 당신이 읽어낼 다음 신호.”** | 피아노 마지막 음과 잔향. |

## 연출 포인트

- 웃기려고 대사를 과장하기보다 진지하게 연기한다. 말 사이의 쉼과 표정으로 반전을 살린다.
- 200억 개의 규모는 반전 직후에 처음 공개한다. 인터뷰의 감정선을 유지하면서도 숫자를 3초간 읽을 수 있게 하고, 마지막 로고 장면에서 한 번 더 강조한다.
- 반전은 30초 전후에 공개한다. 남은 시간에는 서비스가 무엇인지 충분히 보여준다.
- 두 사람의 다른 판단은 같은 데이터를 함께 살펴보는 이유로 연결한다.
- 출연자 2명, 인터뷰 공간 한 곳, 노트북으로 촬영한다. 자체 자막 디자인과 음악으로 프로젝트만의 분위기를 만든다.

## 길이 조정

- **60초 버전:** 초반 교차 편집을 줄이고 20초쯤 별빛이라는 사실을 공개한다. 반전 이후 200억 개 숫자 노출은 유지한다.
- **90초 버전:** 반전 이후 두 사람이 주기를 조정하고 서로의 근거를 확인하는 짧은 대화를 추가한다.

## 제작 전 확정 사항

- 실제 시연 가능한 서비스 화면과 촬영용 데이터
- Planetory 로고, 마지막 화면에 사용할 접속 주소·QR
- 출연자 A·B, 제작진 질문 음성 담당자, 인터뷰 장소
- 음악 소스, 최종 영상 길이와 화면 비율
