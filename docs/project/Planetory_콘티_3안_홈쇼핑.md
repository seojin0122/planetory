# Planetory 소개 영상 콘티 3안

## 홈쇼핑 — 《이 많은 우주가, 내 화면에!》

- 상태: 공유·논의용 초안
- 목적: 홈쇼핑 광고 형식으로 데이터 규모와 직접 탐사하는 경험을 소개한다.
- 길이: 80초
- 출연: 쇼호스트 A·B
- 구조: 숫자로 시선 끌기 → 의심 → 시연 → 같은 숫자를 참여의 의미로 반복
- 반복 카피: **“200억 개의 데이터! 20만 개의 별! 이제, 당신 차례!”**
- Jira: [S15P21C206-253 — 영상포트폴리오 시나리오](https://ssafy.atlassian.net/browse/S15P21C206-253)
- 상위 참고: [요구사항 명세서](../requirements/planetory-requirements-spec.md)의 핵심 가치와 탐사 흐름을 참고한다.
- 범위: 소개 영상 기획이며 코드·운영 설정·서비스 정본을 변경하지 않는다.

## 오프닝 대사 — 촬영용

진행자의 손짓마다 숫자가 화면을 꽉 채운다.

A: **“데이터가 무려 200억 개!”**
B: **“별이 무려 20만 개!”**
A: **“분산 처리로, 분석 화면까지 단 2초 만에!”**

화면 자막: **200억 개 → 20만 개 → 단 2초!**

‘2초’가 등장하는 순간 효과음을 넣고, 다음 장면에서 음악을 뚝 끊는다.

B: “잠깐만요. 지금 뭘 파시는 거예요?”

## ‘단 2초’ 시연·확인 기준

사용자가 수정한 **“분산 처리로, 분석 화면까지 단 2초 만에!”** 대사를 오프닝에 반영한다. 이 수치는 광고 초안의 문구이며, 현재 문서에서 성능 검증 완료를 뜻하지 않는다.

27–42초 구간에서 **별 선택부터 분석 화면이 준비될 때까지** 실제 소요 시간을 측정한다. 2초 표현은 해당 동작의 측정 결과를 확인한 뒤 최종 영상에 적용한다. 타이머는 해당 동작의 실제 녹화 구간에만 표시한다. 주기를 조정하고 신호를 판단하는 전체 탐사 과정과 구분한다.

분산 처리는 데이터를 미리 준비하는 과정으로 설명하며, 200억 개 전체를 2초 만에 처리한다는 의미로 연출하지 않는다.

## 촬영·편집 핵심

- 오프닝과 엔딩의 구도, 음악, 숫자 등장 순서를 똑같이 맞춘다.
- 처음엔 A가 이끌고 B가 의심한다. 마지막엔 시연을 경험한 B가 먼저 외친다.
- **200억 → 20만 → 나의 탐사** 순서로 좁혀, 규모와 사용자 경험을 연결한다.
- 200억 개 데이터와 20만 개 별은 사용자 제공 수치로 반영한다. 최종 자막에는 집계 범위를 확인해 적용한다.
- 실제 서비스 화면은 시연 가능한 기능과 데이터로 촬영한다.

## 제작 전 확정 사항

- 데이터·별 개수의 집계 단위, 대상 범위와 기준일
- 분석 화면 표시 시간 측정 결과와 측정 환경
- 출연자, 촬영 장소, 음악·효과음과 방송 그래픽
- Planetory 로고, 접속 주소·QR과 최종 화면 비율
